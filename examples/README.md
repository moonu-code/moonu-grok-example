# Exemplo Moonu + grok

[Instalação e uso](grok/README.md) · [Arquitetura](common/README.md)

[Moonu](https://moonu.com.br) · [API Moonu](https://dev.moonu.com.br/)

Mantenha o diretório common junto do cliente. Não há dependência do backend Moonu.
Para verificar a instalação sem consumir IA: `python -m examples.grok --help`.

Antes de publicar, escolha a licença e revise o conteúdo. Não inclua credenciais ou gravações.
Antes de usar, homologue uma chamada real e confirme permissões, transferência e cobrança.
Parar o programa não desconecta o ramal: solicite `connected:false` pela API e confirme a desconexão.
